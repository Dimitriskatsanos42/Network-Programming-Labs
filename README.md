# Network Programming Labs

Hands-on networking and systems programming labs developed in C on Linux environments, focused on TCP/IP communication, socket programming and client-server architectures.

This repository contains networking exercises and implementations related to low-level network programming concepts commonly used in infrastructure, cloud and cybersecurity environments.

# Projects Included

## TCP Client-Server Application
Implementation of a simple TCP client/server communication system using sockets in C.

### Features
- TCP communication
- IPv4 socket connections
- Server listening and client connections
- Dynamic IP and port configuration
- Linux terminal execution

---

## Echo Client-Server System
Implementation of an echo communication system where the server returns received messages back to the client.

### Features
- Bidirectional communication
- Socket-based networking
- Connection-oriented communication
- TCP echo mechanism
